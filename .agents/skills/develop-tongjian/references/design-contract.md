# 已确认的设计约定

## 阅读路径

年表 → 年份/事件 → 独立整页阅读 → 返回原年表位置。
让读者先看见每年发生了什么，再点击读详细内容。保留无单列记事的年份，
不要以精选24个事件代替连续年份，也不要以历史地图作为主要入口。

## 阅读布局

- 桌面：左古文、右白话，按内容组形成两栏对照。
- 两栏共享页面滚动；一组译文对应多段古文时，在同一行显示完整古文。
- 手机：同组先原文、后白话；能切换只读白话或只读原文。
- 采用普通页面，不采用右侧抽屉或阅读模态窗口。
- 保留事件定位、行高亮、注释开关、字号调整、年份下拉、前后年份导航。
- 返回年表恢复此前的滚动位置；浏览器前进后退与当前年份同步。

## 视觉基线

使用技能快照中的实际 CSS 作为基线。总体纸色 `#f4f2ec`，
正文背景 `#fffef9`，墨绿 `#285342`，细边框 `#dfdfd3`。
保留朴素的左右段落分隔、古文宋体与白话清晰字体、清淡译文背景。

用户已明确撤回后来的双页书美化：不要恢复中央圆形段落编号、两侧悬浮卡片、
巨大年份水印、书页徽章或那次加大的字体层次。没有明确要求时，不再主动美化。

## 内容标签

现代事件标题仅供定位；不是原书文字。将原文、胡注与校勘、上传译本的白话、
司马光和太史公等史家评论区别标识。不能把追叙当作所在年实际发生的事件。
