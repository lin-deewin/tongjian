# 最小改编的边界

在移除主持与练习形式时使用这些例子。它们说明如何判断，不要求所有文章套用固定章节数、页数或同一模板。

## 删除题目，保留证据分析

源稿包含：

> 练习：如果范增没有私通，汉方是否仍能制造这场接待？
>
> 参考分析：可以。接待条件由汉方掌握，所以这份材料并不只会在“范增私通”的情况下出现。还需要能直接涉及范增行为、且不完全受同一方安排的材料。

纯文章处理：删除题目与“参考分析”标签，将分析独立为：

> 即使范增没有私通，汉方仍能制造这场接待。接待条件由汉方掌握，所以这份材料并不只会在“范增私通”的情况下出现。还需要能直接涉及范增行为、且不完全受同一方安排的材料。

这里补的是被删除问句中的条件。后面的证据分析仍用原文，不另写一段更宏大的论述。

## 补足指代，不添加结论

题目比较三个命题，随后分析写：

> 前两句分别检查来源与推理连接，第三句作出远超这份材料的永久保证。

删除题目后，应把命题补回句中：

> “这份告发的来源有漏洞”和“增加校尉不必然支持谋反”，分别检查来源与推理连接；“霍光永远不会作乱”则作出远超这份材料的永久保证。

不能顺势写成“昭帝证明霍光绝对忠诚”，也不要删掉后文“找到漏洞不等于证明永久无罪”的限定。

## 分清内容与组织形式

| 材料 | 处理理由 |
| --- | --- |
| 六个案例之间的比较、不同机制需要不同核验 | 属于文章的实质分析，保留 |
| “也要问自己：什么新事实出现时，我愿意改变看法？” | 属于论证中的观察问题，保留；文章可以有提问 |
| 与历史案例相连的现代经验及适用边界 | 不因它曾放在答案区就删除 |
| “适合3至8人”“先填写再翻页”“主持人可以反复问” | 属于教学组织或作答形式，纯文章中移除 |
| 为特定练习虚构的完整情境及其配套答案 | 用户仅要案例文章时可整体移除，不能误当史料 |
| “本册”改为“本文” | 属于媒介称谓调整，不是正文重写 |

## 差异记录与核验

用最简单、可复查的形式列出来源位置、原文、处理方式、改后内容与理由。结构化源稿可用 `page id / block index`；普通稿件可用章节名与段落序号。

分别验证：

- **PDF与可编辑源稿**：源稿确实对应用户认可的PDF，不能仅核对标题。
- **源稿与文章**：保留的正文、引文和图表文字一致；所有变化都有明确理由。
- **文章与交付地址**：网站实际返回的是核验过的文章，而非旧缓存或另一个同名稿。

比较时可消除PDF断行、页眉页脚、零宽连接符等提取噪声，但不要通过删除全部标点、忽略数值或宽泛同义匹配，掩盖字句变化。文字比对不能代替图表与版面的视觉检查。
