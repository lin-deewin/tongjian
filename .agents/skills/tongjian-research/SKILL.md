# 高质量通鉴专题研究

创作让读者愿意读下去、能够查证，并能改变观察方式的历史专题。默认面向普通读者；用户指定其他读者时，相应调整背景说明、术语与研究深度。吸引力来自真实处境中的冲突和转折；深度来自对信息、约束、选择与后果的解释；学习价值来自比较后得到的判断方法及其适用条件。

本用户偏好连续阅读的深度文章。未指定其他形式时，以文章为默认成品，不主动加入主持人、会议、读书会流程、角色扮演、作答区或参考答案。用户另行要求课程、练习或资料包时，按其形式组织；这些形式不决定研究质量。

## 确定问题与交付范围

- 根据用户意图确定读者、专题问题、篇幅与交付形式；已有信息足够时直接推进。用户只给宽泛主题时，先将它收束成一个值得解释的具体问题，不必停下来索取全部写作参数。
- 进入现有项目先读 `AGENTS.md`。只要求创作时交付正文；要求 PDF 或网页时再完成相应制作。创作请求不自动包含公网发布。
- 已认可稿件的改编，以该稿为基准。PDF 转文章、清理主持和练习形式时，使用 [PDF 保真改编文章](../pdf-to-article/SKILL.md)，不重新选题或自行整体重写。
- 新研究可改变论点；修订已认可研究时，先识别用户要求改变的是事实、深度、措辞还是形式，保留其认可的有效部分。

## 先研究，再确定文章的解释

先形成简短研究提纲：核心问题、暂定解释、候选案例各自要解决的疑问、尚待核实处。暂定解释是待检验的假说，不是选材时必须证明的答案。

- 将“识人”“信任”“权力”等宽泛题目转成具体难题，例如：真实的目击为什么仍不足以证明背叛？长期支持怎样同时保留纠错能力？结论应回答这个难题，不能只说它很重要。
- 按解释价值选择案例，而非按人物知名度或年代凑数。每案说明它新增哪种条件、机制或反例；重复同一结论的材料可以合并或舍弃。案例数量服从问题和篇幅，不固定为六案。
- 主动寻找会限制暂定解释的事实、相反结果或不同条件。它们可以来自同一案例，不必为“平衡”硬塞一个无关反例。
- 明确选例范围。代表性案例不等于穷尽全书；声称“全部”“唯一”“始终”前，须定义范围并做覆盖核查。

逐例建立精简的研究记录。表格或笔记均可，保存在工作材料中，不必原样塞进正文：

| 记录项 | 要回答的问题 |
| --- | --- |
| 案例贡献 | 它回答核心问题的哪一部分？与其他案例有何差异？ |
| 来源与时间 | 卷、年、段落；实际发生时间与编年归属是否一致？ |
| 事实与解释 | 原文明记什么？当事人或作者又从中推断了什么？ |
| 处境与选择 | 当时知道与不知道什么？有哪些约束、可行选择及代价？ |
| 行动与后果 | 哪一步改变了局面？哪些结果在当时还不可知？ |
| 竞争解释 | 同一行为或结果还有哪些合理解释？证据能否区分？ |
| 可迁移观察 | 读者下次可以多查什么、改变哪个判断环节？边界是什么？ |

引文及关键事实必须回到原文和前后文核对；搜索摘要、二手转述与记忆只作线索。凡决定主旨、人物评价或因果解释的关键论断，研究笔记中记录其出处、证据能支持到哪里、是否为作者推断。区分正文、胡三省注、校勘和史家评论，标明是谁的判断。多处复述同一记载不能充作独立佐证。资料不足时缩小判断或更换案例，不靠模糊措辞掩盖未完成的核验。

使用本项目数据时，读 [史料定位与核验](references/source-work.md)。它说明段落结构、精确锚点、年份符号和容易误读的时间关系。

## 把研究写成引人入胜的文章

动笔与深度修订时读 [叙事、分析与质量审读](references/craft-and-review.md)，其中有有效写法、失败写法和交付前的审读方法。

- **用具体困境开篇。** 从一份承诺、一条消息、一次艰难选择或异常细节切入，尽快让读者知道谁面临什么问题、判断错了有何代价。避免“历史是一面镜子”等泛泛序言，也不用“惊天秘密”制造不存在的悬念。
- **先让读者看见，再解释。** 给出理解转折所需的背景、行动和短引，随后分析关键连接。可以提前点出结果，但分析须返回当事人当时的信息，不能用后来的胜败替他作答。没有固定章节模版的义务。
- **把深度写在关键处。** 解释承诺为何改变筹码、传递路径如何改变消息、处罚如何改变表达、资源变化如何影响行动等具体关系。概念可以帮助命名，不能代替史料和推理；重复抽象原则或增加字数不算深化。
- **重建决策，保留人物复杂性。** 写出可行选择及其风险，不轻易归结为“贪心”“愚蠢”或“英明”。重要心理判断绑定言行与处境依据；有合理替代解释时说明不确定性，不编造对话、细节和内心独白。
- **区分证据的力度。** 记载了一个行动，不等于证明了行动者的全部动机；一种可能解释，不等于已经证实。反事实可检验“即使这个判断不成立，眼前事实是否仍会出现”，但不能写成未发生的历史，也不能从另一种可能直接推出原判断必错。
- **用比较形成结论。** 跨案比较不同条件、关键转折和结果，说明为何同一种建议在另一案可能失效。结尾回答核心问题，给出读者可采用的具体观察动作及适用条件，而非把各案重新摘要一遍。
- **处理现实迁移的代价。** 区分“可以更确信什么”与“可以采取什么行动”；核查也有时间、资源与关系成本。古代君臣、外交与战争的办法不能直接成为现代生活处方。不要承诺方法保证成功，也不要把无法完全确定写成无法行动。

标题与小标题应说明文章真正解释的冲突或问题，不超过证据范围。图表按认知用途选择：关系图解释角色，路径图解释传递，时间线解释先后，比较表解释差异。无助于理解时不必配图；不固定要求人物图或一案一图。图中的事实关系、推测和因果主张须能区分，不能用箭头把假设画成已证实关系。

## 审读与交付

交付前做事实、论证和阅读三方面审读，具体检查见写作参考。重点修复：引文失实、来源不对应、注释或追叙被误读、用结果倒推原因、把相关性写成充分因果、删除不利于主旨的事实、重复案例以及只有原则没有分析的段落。无法补足的证据应降低结论强度或删掉该项主张。

正文中用自然措辞区分记载与推断；限制紧挨它限制的结论，避免每段重复免责声明。给出读者可访问的来源，也在工作稿中保留关键论断的出处和待核实事项。未解决的关键问题影响主旨时，不能把文章报告为已完成核验。

交付连续的成稿及所要求的辅助材料。简要说明核心问题、案例为何这样选择、实际完成的核验及任何影响结论的资料限制；不必展示全部内部笔记。用户要求修订时，指出实质改变。

### PDF 与网页

- PDF：使用可用的 PDF 制作技能进行排版、渲染与视觉检查。正文与可编辑稿保持一致，出处可读、图表不跨页残缺。PDF 排版不替代研究审读。
- 网页：沿用目标网站设计；本项目保留纸色、墨绿与移动端阅读约定。提供专题目录返回入口，引用优先定位原文段落；新增页面后同步 `research.html` 的标题、简介和链接，不擅自恢复已移除的首页入口。
- 页面或导航改动检查来源链接与目录，具备浏览器能力时验收桌面和手机；静态检查不能称为视觉验收。发布按当前授权与开发技能执行，仅本地任务不自动部署公网。
