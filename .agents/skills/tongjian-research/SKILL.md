# 通鉴专题研究

本技能适用于新增或修订“专题研究”文章。目标是帮助普通读者借历史识别处境、信息、关系和制度中的规律，形成更好的观察方法；不把古人硬套成现代案例，也不把复杂历史压缩成一句做人道理。

## 开始工作

先确认专题问题与交付形式。只写文章时完成史料研究与正文；用户要求网站页面时，再完成页面和目录接入。进入现有项目先读其 `AGENTS.md`，以当前数据和用户约定为准。

## 写作路径

每篇专题沿着稳定的阅读路径展开：

1. **提出现实问题。** 用读者能识别的具体困境开篇，例如信息不全时如何判断可信度，或承诺与利益冲突时关系如何变化。说明问题为什么值得从历史中观察，不预设唯一答案。
2. **交代历史情境。** 说明时代、政治关系和事件背景，让读者知道当事人身处什么局面。避免用现代概念替代当时制度与身份。
3. **呈现原文证据。** 选取能回答问题的《通鉴》段落，给出必要的原文、上下文说明和可直接打开的年表锚点。逐例说明当事人当时知道什么、不知道什么、受什么约束、有哪些选择，以及实际采取了什么行动。
4. **分析人物心理。** 将史料明确写出的言行与基于处境作出的推断分开。可以讨论恐惧、信任、侥幸、忠诚、利益计算等可能动机，但须说明推断依据；史料没有交代时，不编造内心独白、对话或确定动机。存在其他合理解释时一并指出。
5. **提炼观察方法。** 从案例中归纳读者可以带回现实的观察问题或判断步骤，使用有条件的表述，不承诺一种方法必然避免风险或带来成功。
6. **说明经验边界。** 交代史料记载的局限、案例选择范围，以及古代制度和现代处境的差异。指出哪些因素不能直接类比，避免把个案说成普遍定律。

## 史料与引用

- 以项目收录的《资治通鉴》原文为依据。引用必须回到对应卷、年及段落核对，不凭搜索摘要、二手转述或记忆写成直接引文。
- 每个案例提供稳定的阅读链接，通常采用 `reader.html#volume-卷号-year-年份键`。年份键遵循项目约定：正数为公元前，负数为公元后，不存在公元0年。
- 区分正文、胡三省注、校勘信息和史家评论；明确谁在说话、评论针对什么。不要把注释或后世评价误写成事件当事人的原话。
- 原文和白话内容按项目的来源标注规则使用；不得把古文冒充白话，也不得把生成译文署名为柏杨。
- 多个案例应分别呈现其证据和差异。若文章声称“全部案例”或“只有这些案例”，先定义纳入标准并进行覆盖核查；否则说明这是经过筛选的代表性案例，不宣称穷尽全书。

## 案例记录模板

撰写前可先为每个候选案例记录以下内容，避免先有结论再挑材料：

| 项目 | 记录内容 |
| --- | --- |
| 问题关联 | 这个事件具体帮助观察专题中的哪一面？ |
| 来源位置 | 卷、年份键、原文段落及年表链接 |
| 明确记载 | 原文写明了哪些言行、事实和结果？ |
| 当时处境 | 当事人掌握的信息、约束、风险和可选行动是什么？ |
| 心理推断 | 哪些动机是推测？分别依据什么？有哪些替代解释？ |
| 可迁移观察 | 普通读者可以用什么问题审视相似处境？ |
| 适用边界 | 哪些历史条件或个体差异使类比有限？ |

## 专题页面

- 沿用现有专题目录和文章的纸色、墨绿、层级及移动端排版。正文应便于分段阅读，案例标题要说明分析焦点。
- 每篇文章提供返回“专题研究”目录的入口；引用链接应能落到对应年份，避免只链接到首页或卷首。
- 新增文章后更新 `research.html` 的专题目录，检查标题、简介、链接和排序与文章内容一致。不要擅自恢复已经移除的首页专题入口。
- 内容或导航有改动时，检查目标页与引用锚点；浏览器能力可用时验收桌面和手机呈现；若只能做静态检查，应说明这一限制。

## 发布前自检

- 读者能否在开篇看懂问题，以及专题将如何回答？
- 每项关键历史判断是否有可追溯的原文依据？
- 是否清楚区分了史料记载、作者解释和人物心理推断？
- 是否呈现了人物当时的信息、约束、选择和后果，而不只是用结果倒推其必然性？
- 提炼的方法是否具体、有限定，并说明了经验的边界？
- 是否避免把复杂事件改写成单一的成功学或道德训诫？
- 页面目录、年表锚点和移动端阅读是否正常？
