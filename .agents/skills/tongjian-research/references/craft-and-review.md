# 叙事、分析与质量审读

用于新专题写作和深度修订。以下例子提炼自《先别急着相信》；学习其判断方法，不沿用固定六案、标题或篇幅。

## 选题与案例各自要做什么

“判断真伪”是领域，“真实见闻为什么仍会误导”才是可以研究的问题。后者要求解释材料怎样形成、怎样传递、怎样被理解，以及理解如何变成行动。

用一句话写出每个案例的任务。例如：楚怀王展示履约顺序如何改变交涉筹码；甘茂展示政治立场与军事事实为何需要分别判断；项羽展示真实见闻与被暗示关系之间的缺口。若各案都只写成“不要轻信别人”，案例数量增加而解释没有增加。

筛选时问：去掉这一案，会失去哪种重要差异？另一案能否更清楚地展示它？材料是否足够重建关键转折？不要只挑支持主旨的材料：甘茂最终取胜，但增兵也是原因；楚怀王受骗，不意味着一切拖延都是骗局。能够容纳这类限制的解释，比没有反面材料的金句更有价值。

## 现场感来自史料中的转折

吸引力不是补写表情、天气、密谈和心理。用可核验的具体变化形成阅读动力：

- 六百里承诺尚未兑现，楚王先断齐交；张仪三个月不朝，楚王又选择辱齐。这一串行动使读者看见筹码如何消失。
- 楚使看见饭食变化，回报项羽；所见可能真实，但接待安排受汉方控制。转折在材料的来源与解释之间。
- 武帝派使者召太子，使者却没有实际进入，回报仍促成皇帝判断。转折在“发出核查命令”和“取得核查结果”之间。

背景只写读懂转折所需的内容。初次出现的身份、官职与地名可以简要解释；与主题无关的完整生平会拖慢文章。每案结束时让读者多明白一个关系，再转入下一案，不靠“接下来更精彩”作悬念。

引文选择能承担证据作用的短段，旁边解释它支持哪一项判断。长引文若没有具体用途，会把研究工作转嫁给读者；自行概述若隐去关键细节，则会让分析失去检验条件。

## 分析要多走一步，但不能跳过证据

有效的分析链通常包含：发生了什么 → 当时有哪些解释 → 哪种条件或行动改变了局面 → 据此能判断到哪里。它是研究辅助，不要求每节都套相同标题。

| 浅或过强的写法 | 应当追问什么 |
| --- | --- |
| 楚王失败，是因为贪心。 | 他已听到哪些警告？为何把拖延解释成己方做得不够？继续履约怎样减少选择？ |
| 甘茂成功，证明相信下属就会成功。 | 五个月无功在当时意味着什么？盟约与新信息如何冲突？增兵有何作用？ |
| 项羽轻信谣言，失去了范增。 | 报告中的所见是否虚假？谁控制场景？哪种关系被暗示却未被直接证实？ |
| 太子后来杀人调兵，证明最初就是谋反。 | 后来的行动如何发生？原始指控、恐惧下的选择与后来事实能否分开？ |
| 群臣都说是马，说明皇帝分不清鹿马。 | 二世最初怎样反应？谁沉默、谁说鹿？事后处罚如何改变表达成本？ |

重要因果判断需要展示连接过程，并检查其他可见因素。时间先后只能说明先后；若资料只支持“可能促成”“加重了”，不要写成“唯一原因”。反过来，正文有明确记载的造假、处罚或行动，也无须为显得谨慎而一概写成无法判断。

特别检查案例衔接和小结中的“因此”“这种信任带来了”等说法：同一人物、相邻段落或主题一致，都不是因果证据。例如，魏文侯赴虞人之约与拒绝韩赵相攻可共同用于比较守信与原则，但不能仅凭相邻记载，断言赴约形成的信用导致韩赵后来来朝。连贯叙述可以连接主题，不必连接成一条未经证实的因果链。也不要把兑现一次赏金的信号，扩大成一切赏罚都稳定、可预测的证明。

心理分析有解释力的写法是：根据言行与处境说明某种动机为何合理，再指出证据不足以排除的其他动机。无解释力的写法是：“古人性格复杂”“他可能有很多想法”。不能只是换成不确定措辞而不提供依据。

反事实用于检验主张，不用于创作另一条历史线。例如，即使范增没有私通，汉方仍能制造相同的接待，因此接待本身不能充分证明私通。这个检验没有证明范增永远无嫌疑，也没有证明任何目击都不可信。

## 从案例比较获得学习价值

不要将结论统一成“警惕”“保持理性”“多看历史”。写清下次可以改变哪一个观察动作，以及它能解决哪类缺口：

- 承诺：核对交付、履约顺序和暂停条件，而非只判断说话者是否诚恳。
- 转述与见闻：分开记录直接所见和推断，检查场景形成与消息传递路径。
- 众口一致：查看表达不同意见的代价，而非把人数自动算成独立证据。
- 争议中的坚持：检查新增事实和资源变化，不能只凭盟约继续，也不能只凭暂时受挫撤回。

方法之间有张力。楚怀王案提醒核验前保留筹码，甘茂案提醒预期困难不必立即推翻计划；不能把两案都总结成“永远不要追加投入”。交代条件后再谈如何行动，同时承认核查也有成本、拖延也可能丧失机会。

现实类比要比较结构和差异，而非给古人套上“老板、员工、绩效”身份。外交欺瞒、宫廷刑罚和军事用兵的实际办法，不能直接作为人际交往建议。资料没有记载的改进办法，应写成作者提出的观察建议，不能说当事人本来就按此执行。

## 成稿审读

按篇幅选择合适的审读力度，不强制评分或额外报告。较长专题可让独立审读者只读正文和来源，指出实际论断的问题；作者仍须核实其反馈。

1. **事实与来源。** 关键引文能否逐字回查？每个关键概述能否定位？是不是把史家评价写成当事人自述，把追叙编年位置当成发生时间？出处是否真能支持紧邻的论断？
2. **论证。** 核心问题得到回答了吗？每案新增了什么？是否把相关性当因果、推断当事实、未来结果当作当时已知？有没有故意漏掉会削弱主旨的记载？比较能否解释相同建议在不同条件下为何失效？
3. **阅读与学习。** 开头有可理解的具体困境吗？背景和引文是否够用？每个抽象分析能否指回一个具体转折？结论提供的观察动作是否比开篇的常识更具体？删掉重复原则，通常比加长篇幅更有效。
4. **形式。** 默认连续文章是否混入主持安排或填空？图表的关系和方向是否有依据，标题是否夸大？在所要求媒介中，来源与图表能否阅读和访问？

以下问题不能用“文风不错”抵消：关键引文失实；整篇解释依赖无证据的心理；决定性的历史事实未核实；虚构对话或剧情被当作史实；正文与所标来源不对应。先修复或缩小主张，再交付。
