# 史料定位与核验

用于本通鉴项目的研究任务。当前工作区、`AGENTS.md` 和真实数据优先于旧技能快照，不因专题创作重建或修改全书数据。

## 数据与定位

- 原文卷文件：`dist/volume1.json` 至 `volume294.json`。对象有 `years` 数组；年对象包含 `year`、`paragraphs` 等字段。
- 段落的 `plain` 是可用于搜索、核对的正文；`runs` 中 `kind: text` 与 `kind: note` 区分正文和胡注。研究胡注或怀疑 `plain` 丢失语境时回看 `runs`，必要时检查源 EPUB。
- 年份键正数为公元前、负数为公元后，没有 0 年。不要直接当作公历正负年份。
- 精确阅读链接：`reader.html#volume-3-year-313-para-1`，其中段落索引从 0 起。网站内部使用相对链接；需要脱离网站阅读的 PDF 或分享稿使用已确认、可访问的绝对地址。本地预览链接不能标成正式公网地址；没有可用网址时保留卷、年、段落等文字出处，不虚构 URL。
- 同年可能跨卷，保留续篇；`titles`、事件标题及搜索索引只用于发现线索，不是史料原句。

卷 JSON 往往压成一行。先以 `rg --files` 定位文件，再用 JSON 结构搜索段落，避免 `rg` 输出整卷。可临时运行：

```python
import json
from pathlib import Path

needle = "息壤"
for path in sorted(Path("dist").glob("volume[0-9]*.json"),
                   key=lambda p: int(p.stem.removeprefix("volume"))):
    volume = json.loads(path.read_text())
    for year in volume.get("years", []):
        for index, paragraph in enumerate(year.get("paragraphs", [])):
            text = paragraph.get("plain", "")
            if needle in text:
                print(volume["volume"], year["year"], index, text)
```

根据问题选词和候选卷；关键词搜索不是全书覆盖证明，也无法自动找出同义表达。需要核对注释时另外搜索 `runs`，不要把注释命中误称正文命中。

## 从命中到可用证据

找到段落后，读前后相邻段和相关年份；事件跨年时追到重要行动与结局。工作笔记保留卷、年、段落、所支持的论断和必要短引即可。长稿或重复生成任务可保存机器可读核验表，但哈希相符只能证明文字未变，不能证明解释正确。

区分三种时间：编年所在位置、追叙事件实际发生时间、当事人在某时点已知的信息。太子后来杀人调兵，不能反证最初巫蛊指控为真；某年段落追述此前的父子关系，不能全部当成该年新发生的事。卷一前403年包含对魏文侯事迹的集中叙述；引用这组段落可标“载于前403年条”，但不能据此写两个故事“同一年”发生。发生时间不明时省去非必要的日期精度，不编造年表。

直接引文逐字核对，包括人名、数值、否定词及说话者。节引省略应明确；规范换行不应顺便改措辞。古文概述或自行释义属于作者整理，避免署为上传译者的原话。不得把古文当白话，也不得把生成译文署名为柏杨。

注意常见证据越界：

- 未记录某种行为，不等于证明它从未发生；但也不能补写它发生过。
- 书信、游说或指控中的说法，首先证明有人这样说过，不自动证明内容为真。必要时写“某人在信中声称／提起”，不要将待核实的说法变成叙事事实。
- 同一个游说故事的多个报信者，未说明是否同源时，不可擅称独立来源或同一谣言渠道。
- 史家对当事人的评价，说明史家的解释，不自动证明当事人真实内心。
- 一段记载可以支持局部行为后果，不一定能解释一场战争或一个王朝的全部结局。
- 两种文献存在差异时说明差异及选用依据；不拼成看似一致的引文。没有完成异文核对，不声称完成了版本鉴定。

外部学术材料可补充制度、地理和解释，引用其他史料也可形成对读，但须注明作者、作品及实际取得的页码或链接。区分《通鉴》直接记载、外部材料提供的背景和作者解释，不能把外部观点写成《通鉴》原话；存在冲突时说明采用依据。未实际阅读的材料或搜索摘要不能冒充已经核验的学术证据。工具不可访问或资料缺失时，使用已取得的材料缩小范围；不得写出未读过的书页、伪造文献或编造精确出处。
