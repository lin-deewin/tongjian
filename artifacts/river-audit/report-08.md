# 卷 211–240 天灾、饥荒与战争事件核读记录

本轮核读候选 1,711 段，生成 430 条事件（战争 406、天灾 21、饥荒 6；含跨类别记录）和 1,280 条排除项。`coverage.reviewedCandidateIds` 列出全部 1,711 个候选段落，未审候选为 0。事件以正文段落为主单位；明确同年同地的时曲战事合并为一条并保留两处来源锚点。年份沿用项目约定：正数为公元前、负数为公元后，没有 0 年。

逐段核读时区分具体灾情与奏议/追叙，社会性饥荒与军队断粮，以及已发生的军事行动与未实施计划、任命部署和史家评论。每条保留引文都逐字校验为对应 `dist/volumeN.json` 中 `years[].paragraphs[anchor].plain` 的子串；事件状态仅在候选 ID 已列入人工核读覆盖时标为 `reviewed`。

## 覆盖边界

- 输入候选均已阅读和筛查；被排除段落仍可能因事件粒度、语义边界或解释差异造成漏收，排除列表不是“原书绝无事件”的断言。
- 候选提取本身有召回限制，未被候选文件收录的段落不在本次覆盖内。
- 事件表以候选段为主要粒度。除明确重复的时曲战事外，仍可能有段内多事未拆或跨段同一行动未归并。
- 个别事件的细分日期、连续战役关联和跨卷续篇仍可依据更广上下文继续校订；无法确定的归属没有强行补充。
