# 十篇通鉴专题：写作与图文交付约定

本批任务：完成用户已认可的十个选题的高质量连续文章，含解释性图形、原文出处与深度比较。只在本地交付图文成稿，不修改线上站点、现有 dist 或既有专题。

## 文章

- 每篇以约 4000—6000 中文字为工作目标，深度优先，避免凑长度。以具体困境或转折开篇；按需要选择两至四组案例，不能只做生平摘要。
- 史事先提供足够背景、言行与转折，再分析人物当时的信息、可行选择、代价与结果。各案有不同解释贡献；比较须得出有条件的结论。
- 不能补写场景、内心、对话；不能用后来的胜败代替当时的判断。写明反例、其他原因与证据边界，限制紧邻所限制的结论。
- 读者应获得具体的观察方法，同时知道核查、等待、纠错、拒绝或退出也有成本。不把古代政治和战争做法直接当现代处方。
- 不用主持、练习、答题、金句拼盘形式。各篇结构服从问题，避免十篇套用同一章节骨架。
- 只引用实际核验的本地原文；dist/volumeN.json 的 plain 为正文，runs 的 note 为胡注。史家评论单独说明。year 正数为公元前、负数为公元后，0 不存在。注意追叙与编年归属。

## 成稿 JSON

顶层字段：

```json
{
  "number": 1,
  "slug": "judging-talent",
  "title": "主标题",
  "subtitle": "明确核心难题的副标题",
  "summary": "80—120字导读，指出具体问题和读者将理解什么，不夸大结论。",
  "question": "一句话核心问题",
  "blocks": [],
  "sources": []
}
```

blocks 按连续阅读顺序包含：

- 段落：`{"type":"p","text":"正文。[[s1]]"}`。用 `[[s1]]` 关联来源。普通正文使用纯文本；可用少量 `<em>`、`<strong>`，不写其他 HTML。
- 二级小标题：`{"type":"h2","id":"稳定英文锚点","text":"小标题"}`。
- 三级小标题（少用）：`{"type":"h3","id":"稳定英文锚点","text":"小标题"}`。
- 原文短引：`{"type":"quote","text":"逐字核验的原文，不加外层引号","source":"s1","attribution":"某人所言／《通鉴》正文／胡三省注"}`。
- 图：见下。

每篇 sources 通常 10—20 条，覆盖全部关键史实和引文。每条：

```json
{"id":"s1","volume":71,"year":-228,"paragraph":4,"quote":"核验用的连续原文短摘（不是自行改写）","kind":"text","claim":"该处支持文章哪项关键事实；解释能支持到哪一步","limitation":"相关限制、追叙时间或需区分胡注等；无则空字符串","context_checked":true}
```

`paragraph` 从 0 起；kind 只能是 text（正文）、note（胡注）、comment（正文中的史家评论）。quote 不能拼接、省略替换或暗改原句，短而能逐字匹配。叙事跨度较大时引用多个锚点，不能拿一个段落支持整段历史。正文里说明来源局限，不把 notes 当交付成稿。

## 图形

每篇至少两张有实际解释用途的图，一张深入具体案例，一张跨案比较或解释判断条件。图形为可下载 SVG，另生成适配手机的 SVG，不用虚构人物画像或装饰图凑数量。不制造未经支持的数值、打分、概率或地理。

通用字段：`{"type":"figure","id":"唯一英文ID","kind":"comparison","title":"准确图题","caption":"解释如何读图、事实与作者分析的界线，并关联 [[s1]] 等来源",...}`。

支持以下四类；按用途选，不要求固定搭配：

1. `flow`：`steps:[{"label":"短标签","detail":"说明"}, ...]`，3—5步；可加 `links:["箭头表示什么", ...]`，长度 steps-1。caption 必须交代顺序与因果的区别。label 建议不超过14字，detail 不超过50字。
2. `comparison`：`columns:["维度A","维度B","维度C"]`，2—3列；`rows:[{"label":"案例或对象","cells":["对应A","对应B","对应C"]}, ...]`，2—4行。每格建议不超过55字。属于定性比较，不打分。
3. `timeline`：`events:[{"date":"明确时间/阶段","label":"事件","detail":"解释关键变化"}, ...]`，3—6项。不要把追叙的编年位置当实际发生年；不确定时间用相对阶段并在图注说明。
4. `branches`：`prompt:"当时面临的具体问题"`；`options:[{"label":"可行选择","condition":"成立条件","cost":"代价","limit":"此路不能保证什么"}, ...]`，2—3项。若为作者重建的选择，caption 明说；不能伪称当事人列过该决策树。

图中文字必须具体，图后正文要解释其关键差别。不要用几张同义框图重复正文口号。纯结构框架在标题或图注写“分析示意”；不得让箭头暗示未经支持的充分因果。
