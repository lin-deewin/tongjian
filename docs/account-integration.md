## 完成内容

- 发送注册邮件前先验证 4 位图形验证码，支持换图与无 JavaScript 表单。图片绑定会话，5 分钟过期、单次作答，服务端限流；图形验证凭证绑定邮箱，10 分钟有效，最终注册也必须通过。
- 邮箱验证码验证后创建账号，之后使用邮箱、密码登录。保留验证码用途隔离、10 分钟过期、重发限制、错误次数限制及原子消费。
- 密码按用户要求放宽为至少 6 个字符，允许纯数字、常见密码及与邮箱相似的密码；注册、修改和找回密码使用同一规则，仍需两次输入一致。
- 独立“我的账号”显示注册邮箱与验证信息，连接阅读、专题、购买记录和账号安全；无需购买也能使用账号功能。
- 修改密码要求当前密码、CSRF 和限流。成功后保留当前登录、轮换会话标识，其他设备会话失效。管理员继续使用管理后台修改密码。
- 退出为 POST 表单；注册、登录、找回、改密和退出均支持关闭 JavaScript。表单 CSRF 失效时显示可继续操作的中文页面，API 仍返回 JSON。
- 首页、阅读页、专题页导航显示正确登录状态。阅读页登录后保留原事件 hash；浏览器返回缓存页时刷新账号状态。
- 真实 SMTP 配置置于 Git 忽略的 0600 `backend/.env`，邮件使用 `deewins.top` 的 Message-ID 和明确的站点、邮箱、有效期说明。没有把邮箱密码写入源码、模板或报告。
- 旧验证码自动登录建号 API 默认关闭，兼容开关不影响旧账号找回密码。本次图形验证码增加 `accounts.0003_graphic_challenge` 迁移，已在本地应用，保留已有账号与权益。
