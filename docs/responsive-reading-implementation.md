# 手机与电脑浏览器适配：实施记录

日期：2026-10-20。依据：[适配方案](responsive-reading-plan.md)。本次仅本地开发，未部署线上。

**后续调整：用户已撤回本次历史长河改版，现已恢复适配前的长河HTML结构、CSS及JavaScript。下文长河改版及其性能样本属于被撤回版本的历史记录，不代表当前功能；阅读器、年表、人物和专题适配保留。响应式回归已改为验证原版长河控件。**

## 已实现

- 窄屏年表改为年份和年号在上、事件在下；手机事件标题16px，常用独立操作区44px及以上。搜索占独立行，筛选可以展开成多行。
- 返回、前后年、筛选、前后卷等短标签不拆字；长卷名使用可自动增高的完整横排文字。长事件标题自然换行，不靠压缩列宽或省略号承载完整内容。
- 阅读器在960px以下使用手机工具布局；正文同时依据容器宽度和当前字号决定是否上下对照。放大到28px时不会硬塞入窄双栏。白话默认18px、原文19px，保留字号和模式控制。
- 顶部标题允许占独立行，底部上一年、工具、下一年保持横排；按实际工具栏高度和手机安全区预留空间。事件锚点按实际顶部高度定位。
- 调字号、模式、注释和窗口大小时，以当前段落与段内相对位置恢复上下文；字号、模式与注释偏好保存在本机。按帧合并滚动位置采样，避免每个scroll事件都扫描正文。
- 历史长河手机端调整为控制区、图表、概览、事件、完整事件阅读入口。次要定位与缩放收进可展开区域，新增精确年份定位；没有0年。
- 长河手机事件列表默认4条，可展开全部，使用页面共同滚动；桌面事件列表与图表并排。所有单条事件及来源链接保留。
- 触摸横拖增加方向判断；斜向或竖向移动不直接改变年份。取消、旋转和多指中断清理拖动状态。
- 远景400年及全书视图按屏幕位置聚合显示事件数，点击聚合放大到60年；完整事件列表使用原数据。手机Canvas DPR上限2，减少闲置动画，保留后台、离屏和减少动态效果偏好的暂停逻辑。
- 从长河进入独立年份阅读时，返回按钮能识别长河来源；年份、缩放、主题、事件、列表展开状态和返回滚动位置保留。重新加载时等待事件内容完成后再恢复长河滚动位置。
- 独立年份页通过现有生成器同步阅读器界面，静态卷页、人物、专题共享样式也做了横排与窄屏调整。专题宽表格使用局部横向滚动，长篇上一篇/下一篇链接在窄屏可独占整行。

## 性能样本与边界

`scripts/measure_river_browser.py`提供本机Chromium样本，使用390×844、DPR3、触摸环境和4倍CPU降速。可选`--baseline-dir`传入保存的旧版index.html、river.css、river.js进行比较；不传时仅测当前版本。

[本轮样本](../artifacts/responsive-20261020/performance.json)中，手机Canvas像素量从913,500降为343,680，减少约62%。全量事件JSON仍约4.02MB UTF-8，当前样本解析约54ms。rAF回调间隔用于观察主线程空闲程度，不能当作实际绘制FPS或实机帧率；本轮没有宣称达到真实用户LCP/INP目标。

本次没有拆分事件JSON，也未新增统计采集字段。后续可依据真实手机弱网及性能记录决定按年代拆包，避免在没有充分实测时改变事件数据结构。

## 尚需实机验收

- iPhone Safari、微信、华为、小米等真实设备和浏览器。
- 系统大字体、真实浏览器200%缩放、输入法键盘、刘海/底部安全区、折叠屏展开过程及长时间连续阅读。
- 真正的中低端手机、弱网、耗电、内存及真实用户75分位LCP/INP。

WebKit已尝试启动，但本机缺少`libicu74`和`libflite1`等运行依赖，未完成WebKit检查。没有将Chromium/Firefox模拟结果当成Safari或手机实机验收。

## 维护说明

优先修改现有组件样式和生成器，不手工维护第二套正文。修改阅读器共享入口后运行`python scripts/year_reader.py --refresh-shell-only`可仅更新1362个年份页界面；本轮因静态样式资源版本也改变，执行了完整SEO页面生成及检查。本次不改变原书数据、年份排序键、来源顺序或缺译标注。

年表旧回归中“手机展开筛选后所有元素坐标完全不动”的断言已按本方案调整为允许向下换行，同时保留桌面稳定性、可达性、不溢出、键盘及筛选功能检查。
