### 已核对的基线

- 阅读器通过 `reader.html#volume-N-year-Y` 切换内容，初始 HTML 不含逐年正文。fragment 适合阅读定位，不能承担不同内容的独立收录。
- 专题已有静态 HTML、独立标题、description 和 canonical，可先改进搜索表达和内链。
- 2026-10-16 经 IPv6 curl 复核：域名根 `/robots.txt` 和 `/sitemap.xml` 均以 HTTP 200 返回 `Hello from Caddy`；`/tongjian/sitemap.xml` 是有效 XML，包含9个地址。urllib 和网页抓取工具曾被拒绝，不能将其403直接当作真实用户或搜索引擎的访问结果。
- 本地已有 `dist/robots.txt`，但子目录 robots 不能代替域名根文件。根路径修复涉及 Caddy，而不只是增加 dist 文件。
- 当前本地已有451个人物档案及原文出处，可复用经过复核的记录；不表示全部生平完整或全部历史事实得到外部认证。
- 当前目录存在大量本轮之前的未提交改动，尤其是人物核查；本轮不覆盖、撤销或自动发布这些改动。

### 评估结论与调整

1. 建议总体成立；修 robots 和地图是基础配置，独立内容 URL、首次响应正文与普通链接是主要工作。
2. 保留朴素纸色、墨绿、桌面左右对照、手机同组上下排列和旧阅读器，不迁移框架。
3. 静态页从现有 JSON 生成，采用与阅读器一致的译文补充／替换规则，保留缺译、版本差异、注释、追叙与跨卷续篇。不得生成译文补空白。
4. 不把综合专题标题缩成无法代表全文的单案例，不为数量拆出空泛页面，不统一 canonical 到阅读器。
5. 先复用内容验证流程，再根据搜索平台的实际查询词和曝光扩展。生成页面数量不是收录或排名结果。
