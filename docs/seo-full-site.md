# 全站 SEO 改造（2026-10-16）

## 授权与范围

讨论过程见 [SEO 讨论记录](seo-discussion.md)，初始5卷／3人试点配置保留于 `scripts/seo/pilot.json`。

## 从试点扩展的取舍

- 全书294卷均已有完整原文与稳定配对顺序，全部生成独立卷页。没有为1362年再复制一套独立正文页，以免制造大量重复入口；每年和每段有卷页内稳定锚点。
- 本地451个人物档案中69人的全部已收录条目具有明确、有效的上下文复核记录（共278条），可生成独立人物页。
- 其余382人仍有待核对条目，继续通过现有阅读器访问，不列入独立人物页面和站点地图。排除清单及原因自动保存在 `dist/seo-manifest.json`；不补授审核、不改动人物数据、不以SEO任务代替史料终审。
- 页面能核对来源，不等于传记完整或获得外部史学认证。人物页保留收录范围、追叙、评论及记载位置说明。
- 全卷无可对应白话时，搜索标题明确“白话缺译”；逐段仍完整提供原文。不会将古文、待核译本或生成译文称作可靠白话。

## 页面与导航

- `reading.html`：全站阅读入口，连接十六纪、人物目录、原阅读器和全部六个专题。
- `volume/`：294卷完整目录，按十六纪分组，具有可抓取的普通链接。
- `volume/1/` 至 `volume/294/`：全卷原文、胡注、可对应白话、缺译提示、译本差异与待核原文，保留每年年头、卷首、原书衔接与插图。提供逐年／事件锚点、上下卷和同年续篇。
- `people/`：69位已核读人物目录，初始HTML完整，姓名／别名筛选只是增强功能；可转到阅读器浏览其他人物。
- `people/{id}/`：已核读人物记载、完整引文、记载与实际时间区别、静态卷页与原阅读器深链。
- 卷页仅根据原有段落—人物位置映射连接已核读人物，不以人名全书字符串替换猜测身份。
- 现有六个专题的出处链接指向相应静态原文段落；保留进入交互阅读器的入口和原地址的兼容行为。

## 抓取与元数据

- 生成页各有唯一标题、描述、自身canonical、Open Graph分享信息及JSON-LD。目录、人物资料集合和卷页章节按实际内容表示；不制造出版日期、译者认证或评分。
- 现有首页、阅读器、专题目录及六篇专题统一规范地址和分享信息。JSON-LD只描述访客可访问内容；付费试读使用普通WebPage，不暗示完整付费正文免费公开。
- `home.html` 兼容入口保留 noindex，并声明主入口canonical；`account.html` 增加 noindex。后台私有路径已有鉴权、private/no-store 与 X-Robots-Tag，未更改。
- 阅读器增加静态目录入口及无JavaScript提示，去除面向开发过程的“你上传”表达。
- 地图从明确的公共页面重建，不保留已撤下或不合格人物的旧条目。当前366个生成页，加9个既有公共入口，共375个规范地址；地图没有fragment、账号页或受保护付费页面。
- 根robots与地图索引已通过生产Caddy精确路由接入，保留现有账号和代理配置；配置变更已验证并重载。
- 新CSS／JS使用内容摘要作为资源版本号；插图保留尺寸，避免因加载后才确定大小造成阅读位置移动。

## 维护

全站配置：`scripts/seo/site.json`；`volumes: all`、`people: reviewed` 根据当前数据选择，人物复核有效且完整时，下次生成自动纳入。

```sh
python scripts/build_seo.py
python scripts/check_seo.py
python scripts/check_seo_browser.py
node scripts/check_reader.cjs
python scripts/validate_full_book.py --original sources/hu-sansheng.epub
```

在重建卷、译文补充、人物档案、原专题公开HTML后运行上述生成流程。SEO生成不调用付费文章构建器，不改写私有交付。若重建付费公开预览，随后运行 `build_seo.py` 恢复公开页元信息与原文链接。

`seo-manifest.json` 保存输入、配置、资源、元数据、生成页摘要和未纳入人物。来源、译文补充、人物语义复核绑定失效则拒绝生成；原文配对重排／漏段也拒绝。移除已不合格人物时，只删除原生成器管理且未被手工修改的旧HTML，不动人物JSON或其他页面。
